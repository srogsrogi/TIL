# 배포 강의 ver.3

## 개요

- SSAFY 2학기 프로젝트 마무리 후 팀원과 함께하는 스터디

- 강의 자료는 2회차 수업자료와 팀 멘토링 로그 등을 복합적으로 활용할 것이나 학생 본인의 언어로 작성된 강의 노트를 만드는 것을 권장



## 학습자 분석 & 강의 계획

- 학생 목표는 다음 프로젝트에서 Infra를 담당하기 위해 필요한 기술을 습득하는 것
  - 웹 앱을 포함한 서비스를 배포하고
  - 서버 단에서 일어나는 문제들을 해결할 수 있어야 함

- 개발 경력도 좀 있고, 프로젝트 내에서 이미지/컨테이너나 docker 명령어 자체는 얕게나마 경험해봤고..
  - 1~2회차 학생들에 비하면 기술적인 부분은 더 빠르게 습득할 수 있을 것으로 예상
  - 그래서 이번 강의는 GPT로 때울 수 있는 기술에 대한 설명은 좀 더 빠르게 진행하고
  - 아키텍쳐 설계 철학, 디버깅 플로우, AI 활용법 등 프로젝트 진행 시 직접적으로 겪을 문제들에 대한 메타적 이해를 심어주는 데에 좀 더 집중하고자 함
  - 대신 실습이나 과제는 1~2회차보다 훨씬 challenging할 듯
    - 학생에게 요구하는 자습 시간을 늘리고
    - 과제할 때 질문도 받고 같이 봐주면서 보완할 것
- 실습&과제는 항상 학생이 하고 싶어질 만한 것으로..
  - 수업 시간 내 실습은 1~2회차와 마찬가지로 간단한 형태의 파일들로 진행하고
  - 복습 과제로 1학기 때 진행하신 프로젝트(프론트+백 구조의 웹앱)를 배포해보기로 함



## 강의 일정

- 2.11~2.13 3일 간 연속 오프라인 강의(일 1.5~2h)
- 이후 필요에 따라 연휴 기간 중 온라인 수업 진행하거나 학생이 필요로 하는 포인트들만 짧게 짚어줄 예정



## 커리큘럼

### 1일차

- 가상 환경
  - 가상 환경 개념
  - venv, conda, uv 비교
- Container
  - Image, Container 개념
  - Docker / DockerHub 활용
- VM
  - VM 개념 및 Container와의 비교
  - AWS EC2 활용
  - 그 외 AWS 서비스 둘러보기

### 2일차

- Reverse Proxy
  - 프록시 개념
  - nginx 역할
  - nginx 활용(컨테이너 / 전역)
- DNS
  - DNS 개념
  - namecheap 도메인 구매 및 DNS 설정
- SSL/TLS
  - HTTPS / SSL 개념
  - certbot 및 nginx 활용

### 3일차

- Docker compose

  - 멀티 컨테이너 실행
- GitHub Actions / GitLab CI·CD
  - Actions 서버의 동작
  - CI
  - CD
  - 설정 파일 읽는 법
